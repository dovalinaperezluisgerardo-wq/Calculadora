🧮 Calculadora Full Stack

Aplicación web Full Stack desarrollada con Python, FastAPI y JavaScript, diseñada para demostrar la comunicación entre un frontend y un backend mediante una API.

🚀 Características

* Operaciones matemáticas encadenadas.
* Comunicación entre frontend y backend.
* Consumo de API mediante Fetch API.
* Intercambio de información mediante JSON.
* Validación de datos.
* Manejo de excepciones.
* Programación Orientada a Objetos.
* Interfaz web desarrollada con HTML y CSS.

🛠️ Tecnologías

* Python
* FastAPI
* JavaScript
* HTML5
* CSS3
* Fetch API
* JSON

🎯 Objetivo

El objetivo del proyecto es demostrar la integración de tecnologías frontend y backend en una aplicación funcional, utilizando una API desarrollada con FastAPI.

📚 Lo que demuestra

Este proyecto demuestra conocimientos prácticos en:

* Desarrollo Full Stack.
* Desarrollo de APIs.
* Comunicación cliente-servidor.
* Python y FastAPI.
* JavaScript.
* JSON.
* Validación y manejo de errores.
* Programación Orientada a Objetos.
